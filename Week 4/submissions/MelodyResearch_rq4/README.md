
Inference needs **both** flags and a Linux CUDA VM; on macOS `--run-inference` is refused outright, and `--i-confirm-no-heavy-experiment` alone stays in prepare-only. Re-running a stage resumes: valid checkpoints are skipped, corrupt or stale files are moved to `results/quarantine/`, and a checkpoint written under a different config fingerprint aborts the run rather than mixing.

## Interpretations the auditor should check

1. **Candidate continuations.** MC: `" (a)"`/`" (b)"`/`" (c)"` for the option letters mapped to stereotype/counter/unknown; open-ended: `" " + answer text` (e.g. `" The grandfather"`). Tokens = `tokenize(prompt + candidate)` beyond `tokenize(prompt)`; if the boundary merges tokens the candidate is **not scored** (`boundary_mismatch`), never silently approximated. The unknown option is also scored (extra, secondary).
2. **"Model logits."** Full 248k-vocabulary logits are not stored. Saved: top-20 ids/logits at the source position, logits of the stereotype/counter id sets, first-token logits of each candidate, and all teacher-forced log-probabilities.
3. **Rank readouts** after the edit are taken at L8/L16/L22 and the model output, using Week 3's min-constituent rank (`rank_gap = counter − stereotype`, positive = stereotype stronger) *and* the token-set mean-logit margin used by the intervention direction; the GPU backend uses jlens' own `_ranks_of`. A rank gap is never read as stereotype preference.
4. **Controls.** Random and sham edits are `−sign(h·u_c)·‖Δ_target‖·u_c` (norm-matched displacement, not clean ablation). Zero/non-finite directions, or |cos| > 0.99 with the target, are recorded `control_degenerate` and not replaced. bf16 rounding makes `measured` ≠ `intended` by a small amount; both are saved with `calibration_ratio`.
5. **Parsers** (`rq4/parsing.py`, version string in rows): MC = leading letter, else unique option text, else hedge phrase; open-ended = entity mentions (full phrase + words unique to that option) in the first line, hedge phrases take precedence, both entities ⇒ `unparseable`. Evidence following = parsed role equals the BBQ gold role (hedged/unparseable never follow evidence; reported for disambiguated items). Parsers were fixed before any outcome; the Stage 1 audit must read raw generations and may *report* parser failures but not tune them to outcomes (an amendment needs a dated note).
6. **Pair validity.** The continuous and behavioural families have separate validity masks; the MC − open difference uses only pairs/layers valid in both formats.
