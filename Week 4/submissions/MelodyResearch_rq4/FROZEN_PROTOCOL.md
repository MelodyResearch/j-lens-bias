# Frozen protocol, version 1 — 2026-10-20

Freeze this document before implementation or access to new intervention outcomes. Implementers must reread it at each coding stage. Amendments require a dated note that states whether any outcomes were already inspected. No outcome-driven choice of layer, strength, parser, items, or metric is permitted.

## Scope and hypotheses

The question is whether Week 3's large multiple-choice versus open-ended J-Lens rank-gap difference corresponds to a similarly large *causal* effect on outputs. H1: format amplifies the readout more than causal leverage. H2: format changes causal leverage in the same direction. H3: target intervention does not exceed controls. H4: a targeted effect exists but does not improve stereotype-dependent behavior or preserve evidence following. All four remain open.

Use only `Qwen/Qwen3.5-0.8B` and the released `qwen-n1000` Jacobian Lens. Do not train or refit either. Use `Week 2/data/age_selected_items.jsonl` and the Week 3 prompt builder and raw results as immutable inputs. Freeze the ten base item IDs, all four BBQ conditions, and both formats before loading the model. Verify each open-ended question for intelligibility without looking at intervention outcomes; record any exclusion and retain matched pairs only. There are at most 40 matched pairs and 80 prompt evaluations, and only ten independent base items. Do not represent this development set as independent confirmation.

## Intervention and locations

First confirm the lens has exactly fitted source layers 0–22 and verify the mapping from a lens source layer to the corresponding model block output. Prespecify single-block intervention sites L8, L16, and L22; no layer sweep may choose a winner. At the final prompt token, verify the decoded source token is `:` from `Answer:` in both formats. Apply a clean projection ablation at this position on the block output; use a cloned tensor and remove hooks in `finally`. Intervene only during prefill, not on every generated token. For the main direction at layer l, use the contrast between the J-Lens transported unembedding vectors of the official BBQ stereotype and counter targets: `J_l.T @ (mean(U[meaningful_stereotype_ids]) - mean(U[meaningful_counter_ids]))`, then unit-normalize. Tokenize the *complete* target phrase as a continuation with its leading space. Deduplicate constituent IDs, use the repository's meaningful-token mask, and log all chosen IDs. A phrase with no meaningful token or two targets with identical token sets makes that pair ineligible. This token-set contrast is an intervention direction, not the Week 3 min-constituent rank-gap statistic; label it accordingly.

Arms: A clean baseline; B projection ablation along the verified contrast; C three fixed-seed random directions (seeds 11, 23, 47); D an unrelated semantic contrast, `banana` versus `table`, transformed through the same lens. Calibrate the random and sham displacements to the target ablation's measured norm for each clean activation and report the calibration, while capping all displacement at 10% of that activation's norm. If the target projection would exceed this cap, mark the item/layer as safety-excluded rather than silently weaken it. If the sham or random projection is degenerate, record the failure rather than silently replace it. The control edit may be scaled along its own direction; describe it as a norm-matched displacement rather than clean ablation. Do not include Gaussian or two-pass swap unless core arms complete and a dated, outcome-blind extension is recorded. Never use single-pass multilayer swaps.

## Outcomes and estimands

For each arm, layer, item, condition, and format save the exact prompt hash, target IDs, displacement norm and ratio, J-Lens stereotype/counter target ranks and rank gap, model logits, full-sequence teacher-forced log probabilities for both candidate answers, greedy generated continuation, and its rule-based classification (stereotype, counter, unknown/hedged, unparseable). For multiple choice score the actual mapped option letters as continuations; for open-ended score the actual answer phrases as continuations. Derive candidate continuation tokens by tokenizing the *prompt plus complete candidate*, not by `encode(candidate)[0]`. The two formats have different answer spaces, so compare each intervention with its own format's clean baseline before comparing matched effects across formats. Audit text parsing before outcomes; preserve all raw generations and ambiguities. On disambiguated items also report whether the generated answer follows BBQ evidence. Never treat a negative rank gap as stereotype preference.

Primary continuous comparison: per pair and layer, the absolute change from clean in the within-format full-answer log-probability margin under B, minus the mean corresponding change under the three C seeds. Report the paired MC-minus-open-ended difference, stratified by layer, with all item values. D is a second control. Co-primary behavioral evidence is the within-format change in *classified generated answers* under B versus controls, including unparseable/hedged responses; compare paired MC and open-ended changes. Do not claim a causal *behavioral* effect when only teacher-forced scores or readouts move. Secondary outcomes: signed margin changes, rank-gap changes, evidence accuracy, unknown/hedged rate, and displacement. No optimization for a positive effect.

Aggregate the four conditions within each base item first. Report ten-item means and a base-item clustered bootstrap interval (2,000 resamples, seed 20261020) for the paired difference, plus item-level results and seed spread. With ten items, interpret intervals cautiously and avoid unqualified significance or debiasing claims. A directional behavioral change that simply reverses which group is preferred is not neutralization.

## Validation and staged execution

Stage 0 is preparation only: inspect inputs, metadata and prompt semantics, assert model/lens dimensions and token mappings using lightweight fixtures where possible, and test alpha-zero identity, exact hook site and position, shape/dtype, cleanup on exception, deterministic controls, token deduplication, finite outputs, displacement cap, format handling, and source-layer mapping. Stage 1 is one base item across its four conditions and both formats; inspect actual generations and system memory before expansion. Stage 2 is the frozen ten-item set only if Stage 1 passes and memory remains safe. Use one model process, sequential inference, atomic per-evaluation checkpoints, resume with schema validation, and no repeat of Week 1–3 inference. Preparation must be the default CLI mode. Stop for memory pressure, swap growth, unexpected MPS allocation growth, duplicate model jobs, invalid hook alignment, nonfinite values, or failed controls. Preserve a pilot and label it `PILOT_ONLY` if full execution is unsafe. No cloud purchase.

The completion gate requires matched pairs, unique rows, all core arms, actual generated outputs, correct roles and tokenization, control comparisons, base-item uncertainty, saved raw results, and figures rebuilt solely from those results. A completed but unreliable comparison is `INCONCLUSIVE`; a small run is `PILOT_ONLY`; an unavailable model or unsafe machine is `BLOCKED`.
